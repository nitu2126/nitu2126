### 👋 About Me

</div>

I'm an **Embedded Developer** with **2+ years of hands-on experience** at **SOPA Systems Pvt. Ltd.**, where I design and build firmware for microcontroller-based products deployed in real-world industrial environments. My work sits at the intersection of hardware and software — from low-level peripheral drivers and communication stacks to remote telemetry and diagnostics.

I enjoy solving problems that live close to the metal: making devices talk reliably over noisy links, recovering gracefully from faults, and turning prototypes into field-deployable systems that quietly keep working for years.

### 💼 Professional Projects

<sub>Firmware & implementation details remain confidential. These summaries describe engineering scope only.</sub>

</div>

<br/>

<details>
<summary><b>🔆 &nbsp;Solar Plant Automation & Tracker Control</b> &nbsp;·&nbsp; <i>dsPIC33 · Deployed on field</i></summary>
<br/>

> **Platform:** dsPIC33 series microcontroller  
> **Role:** Firmware Developer  
> **Status:** 🟢 Deployed & under observation

Redesigned and redeveloped firmware for a multi-table solar tracking system to overcome existing field flaws and add full remote-control capability.

**What I built**
- Firmware for a distributed network of tracker controllers connected to a **central server → Network Control Unit → tracker controller** architecture.
- Integration of tilt sensors, motor drivers, motor-current sensing, RTC, and battery-voltage monitoring.
- XBee API-mode mesh communication with custom **telemetry** and **heartbeat** frames.
- Remote commands for setpoint updates, delays, GPS coordinates, calibration, cleaning, hazard mode, night mode, and fault clearance.
- Priority-based operation modes, calibration workflows, and detailed fault reporting (stall, reverse motion, slow movement, communication gaps, and more).
- Setpoint calculation on the tracker side using the NREPL backtracking algorithm.

**Outcome**
- Field deployment with **48 tracker controllers** on a single coordinator.
- Auto command cycle every 30 seconds with periodic heartbeat reporting.
- Fully remote-configurable — setpoints, delays, and modes can all be updated from the central GUI.

</details>

<br/>

<details>
<summary><b>🌱 &nbsp;Polyhouse Environmental Monitoring System</b> &nbsp;·&nbsp; <i>STM32 · Running ~1.5 years</i></summary>
<br/>

> **Platform:** STM32L4 series microcontroller  
> **Role:** Firmware Developer  
> **Status:** 🟢 Deployed in an operational polyhouse

An end-to-end environmental and crop-monitoring system built on a single board that gathers data from multiple industrial sensors and transmits it wirelessly.

**What I built**
- Integration of industrial RS-485 sensors for environmental, soil, crop-solution, and weather measurements — including **temperature & humidity**, **soil temperature, moisture, EC & pH**, **photosynthetically active radiation**, **EC**, **dissolved oxygen**, **pH**, and an **integrated ultrasonic weather station**.
- RTC-based timestamping and XBee XR868 wireless transmission using custom data frames per board type.
- **Cyclic external flash logging** so no data is lost when the master goes offline — unacknowledged frames are stored and re-sent automatically once the link returns.
- Remote configuration of RTC, transmission intervals, and flash memory.
- DIP-switch based device addressing for multi-board deployments.

**Outcome**
- Live dashboard with data logging and Excel export for analysis.
- Grafana cloud visualisations for long-term environmental trends.
- Stable in production for roughly **1.5 years** without hardware changes.

</details>

<br/>

<details>
<summary><b>🌐 &nbsp;Four-Port Serial-to-Ethernet Gateway</b> &nbsp;·&nbsp; <i>STM32 · Completed</i></summary>
<br/>

> **Platform:** STM32F4 series microcontroller  
> **Role:** Firmware + Desktop App Developer  
> **Status:** ✅ Completed

A configurable industrial gateway that bridges four serial ports to Ethernet with real-time, bidirectional data flow.

**What I built**
- Firmware for a **TTL-to-Ethernet module** integrated with an STM32 host controller.
- Each port independently configurable as **RS-232 or RS-485** based on a 4-pin DIP switch, with per-port serial parameters.
- Non-blocking communication using **interrupts and DMA** across all four ports.
- RTC timestamping for every transmitted frame.
- A desktop application for live device data, port/module configuration, RTC setup, and data logging.
- AT-command-based configuration for the Ethernet module.

</details>

<br/>

<details>
<summary><b>🔋 &nbsp;Solar String Current Monitoring Solution</b> &nbsp;·&nbsp; <i>STM32 · Under deployment</i></summary>
<br/>

> **Platform:** STM32L4 series microcontroller  
> **Role:** Firmware + App Developer  
> **Status:** 🔄 Under deployment

An eight-channel monitoring system for tracking string output currents in a solar plant, with live visualisation and logging.

**What I built**
- **8-channel monitoring** for high-current solar strings.
- External ADCs over a shared I²C bus for multi-channel measurement.
- Analogue signal-conditioning circuitry (op-amp unity-gain follower) for bipolar Hall-effect sensor output.
- External flash storage for frames, RTC timestamping, and custom hex frames over Ethernet.
- Red/green LEDs per channel and a buzzer for fault indication.
- A desktop application with live current visuals, periodic polling, and Excel report export.

</details>

<br/>

<details>
<summary><b>📡 &nbsp;XBee-to-Ethernet Gateway</b> &nbsp;·&nbsp; <i>STM32 · Completed</i></summary>
<br/>

> **Platform:** STM32L4 series microcontroller  
> **Role:** Firmware + App Developer  
> **Status:** ✅ Completed

A bridge device that receives XBee wireless telemetry and forwards it over Ethernet to a central system.

**What I built**
- XBee XR868 (API mode) integration with a TTL-to-Ethernet module.
- RTC-based timestamped transmission using a custom frame format.
- External flash memory for buffering/logging.
- 4-pin DIP switch for device addressing.
- A monitoring application with AT-command Ethernet configuration, RTC setting, and data logging.

</details>
